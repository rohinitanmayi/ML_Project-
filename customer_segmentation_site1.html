PCA — Explained Variance

Components needed to retain 90% of the dataset's total variance: 8 out of 13 possible.

Pipeline Overview

  1. Clean missing values (median imputation)
  2. One-hot encode categorical features (device, category)
  3. Standardize all features (zero mean, unit variance)
  4. Run PCA → reduce to 8 components (90% variance retained)
  5. Run t-SNE on PCA output → 2D embedding preserving local structure
  6. Run KMeans (k=4) on PCA-space → assign cluster labels
  7. Profile clusters → assign business-meaningful segment names
